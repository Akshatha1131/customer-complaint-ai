# AI Complaint Management System

## Features

- AI Complaint Extraction using Groq LLM
- PDF Complaint Upload
- AI Complaint Analysis
- Complaint Form Auto-fill
- PostgreSQL Database
- Complaint History
- FastAPI REST APIs
- React Frontend

## Tech Stack

- React.js
- FastAPI
- PostgreSQL
- SQLAlchemy
- LangChain
- Groq API
- PyPDF

## Run Backend

```bash
cd backend
source venv/bin/activate
uvicorn app.main:app --reload
```

## Run Frontend

```bash
cd customer-complaint-ui
npm install
npm run dev
```
